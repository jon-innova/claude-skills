# claude-skills

Skills de Claude Code.

| Skill | Qué hace |
|---|---|
| [`session-handoff`](session-handoff/SKILL.md) | Resumen de fin de sesión, solo en el chat, para que un agente nuevo continúe tras `/clear` |

## Instalar

Copiar la carpeta de la skill a `~/.claude/skills/`:

```bash
git clone https://github.com/jon-innova/claude-skills.git
cp -r claude-skills/session-handoff ~/.claude/skills/
```
